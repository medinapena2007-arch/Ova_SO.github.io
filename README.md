# OVA: Memoria virtual

Objeto Virtual de Aprendizaje (OVA) desarrollado como recurso académico para la asignatura **Sistemas Operativos** de la **Universidad Simón Bolívar, sede Cúcuta**. El recurso presenta de forma visual e interactiva los conceptos fundamentales de la memoria virtual y su papel en la administración de memoria de un computador.

## Descripción del proyecto

Este OVA es un sitio web educativo de una sola página que permite consultar los fundamentos de la memoria virtual mediante explicaciones, esquemas, tablas, recursos audiovisuales y una simulación interactiva de reemplazo de páginas.

Su diseño utiliza una identidad visual institucional basada en tonos verdes, azul oscuro y cian, con elementos animados relacionados con la memoria de un computador. La interfaz se adapta a diferentes tamaños de pantalla.

## Objetivo

Facilitar la comprensión de la memoria virtual, su funcionamiento y los mecanismos que utilizan los sistemas operativos para administrar la memoria y atender los accesos a páginas.

## Contenidos

El recurso está organizado en los siguientes apartados:

1. Introducción a la memoria virtual.
2. Fundamentos de la memoria de un computador.
3. Concepto y utilidad de la memoria virtual.
4. Funcionamiento y traducción de direcciones.
5. Paginación y fallos de página.
6. Algoritmos de reemplazo de páginas.
7. Archivo de paginación y área de intercambio (swap).
8. Rendimiento, ventajas, limitaciones y aplicaciones.
9. Glosario de términos clave.
10. Conclusiones.
11. Bibliografía y fuentes de consulta.

## Características principales

- **Recurso de consulta:** contenidos explicativos sobre memoria RAM, direcciones virtuales y físicas, MMU, tablas de páginas, paginación y fallos de página.
- **Simulación interactiva:** permite avanzar por una secuencia de referencias a páginas, observar los marcos de memoria y consultar los aciertos y fallos registrados.
- **Algoritmos incluidos en la simulación:** FIFO (First In, First Out) y LRU (Least Recently Used).
- **Navegación por secciones:** menú lateral con enlaces a los temas del OVA.
- **Indicador de progreso:** barra superior que muestra el avance de lectura en la página.
- **Diseño adaptable:** distribución optimizada para computadores, tabletas y teléfonos móviles.
- **Elementos visuales dinámicos:** animaciones y recursos gráficos relacionados con RAM, páginas y área de intercambio.
- **Accesibilidad visual:** contempla la preferencia del sistema para reducir el movimiento de las animaciones.
- **Fuentes de consulta:** enlaces a libros y documentación técnica recomendada.

## Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.

## Cómo ejecutar el proyecto

Como el OVA está construido en un único archivo HTML, puedes abrirlo directamente:

1. Descarga o clona este repositorio.
2. Ubica el archivo HTML principal.
3. Ábrelo con doble clic o arrástralo a un navegador web.
4. Navega por las secciones desde el menú y utiliza los controles de la simulación.

### Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
cd NOMBRE_DEL_REPOSITORIO
```

Después, abre el archivo HTML principal en tu navegador.

> Reemplaza `URL_DEL_REPOSITORIO` y `NOMBRE_DEL_REPOSITORIO` por los datos reales de tu repositorio de GitHub.

## Estructura del proyecto

La versión entregada del OVA está contenida en un archivo HTML independiente. Una estructura sencilla para publicarlo en GitHub puede ser:

```text
OVA-Memoria-Virtual/
├── index.html
└── README.md
```

Puedes renombrar el archivo HTML entregado como `index.html` para que sea reconocido fácilmente como página de inicio al publicar el proyecto con GitHub Pages.

## Publicación con GitHub Pages

Para publicar el OVA como sitio web:

1. Sube `index.html` y `README.md` a la rama principal del repositorio.
2. En GitHub, entra a **Settings**.
3. Selecciona **Pages** en el menú lateral.
4. En **Build and deployment**, elige la opción **Deploy from a branch**.
5. Selecciona la rama principal (`main`) y la carpeta raíz (`/root`).
6. Guarda los cambios y espera a que GitHub Pages genere el enlace del sitio.
